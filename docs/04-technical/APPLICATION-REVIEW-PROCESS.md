# Application Review Process

## Who reviews

A person on the Code Yaar founding team reads each application. Not automated, not algorithmic.

## Criteria

Motivation, willingness to learn, interest in practical work, collaboration, realistic availability. Not existing skill level, follower counts, institution names, or country.

## Steps

1. Application submission (five-step form)
2. Application review by the team
3. Selection notification by email (timeline not yet published — no date promised)
4. Onboarding (community guidelines, introductions, first optional activity)

## Caveats

- Submitting does not guarantee acceptance
- Places limited to one hundred founding members
- Review turnaround time not published

## Communication

Selected applicants contacted by email using the application address. No decisions via social media.
