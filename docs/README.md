# Code Yaar — Global Founding Community

Documentation for **The First 100**, the founding community initiative of Code Yaar.

This documentation is written for three audiences:

1. **The founding team** — who need the vision, strategy and operating model in one place.
2. **Engineers** — who need the architecture, standards and form specification before changing code.
3. **Future contributors** — who need to know what is decided, what is still open, and why things are the way they are.

## Status labels used in these documents

| Label | Meaning |
| --- | --- |
| **Confirmed** | Stated directly in the project brief or by a founder. |
| **Implemented** | Exists in this repository and was verified in a build or by inspection. |
| **Recommendation** | Proposed by the engineering/design side. **Not yet a founder decision.** |
| **TBD** | Deliberately unresolved. Must not be presented to the public as settled. |

## The most important rule

The website must never describe a planned or imagined capability as an existing one. If a document here says **Recommendation** or **TBD**, the public site must not contradict it.
