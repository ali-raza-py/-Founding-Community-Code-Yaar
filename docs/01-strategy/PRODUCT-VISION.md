# Product Vision

## Organization
Code Yaar

## Initiative
Code Yaar Global Founding Community

## Campaign
The First 100

## Program
Global Founding Cohort 2026–27

## Tagline
Think. Build. Evolve.

## Core message
One community. Different countries. One shared ambition.

## Vision statement

The founding community is an early, separate initiative that exists to bring motivated learners together while the Code Yaar platform is being built. Founding members are participants, not an audience — they test early ideas, contribute feedback, and establish the culture that later members will inherit.

## Non-goals (explicitly not promised)

- No guaranteed internships, jobs, scholarships, or certifications
- No employment or career-outcome promise from Code Yaar
- No fixed review timeline or onboarding date
- No certificate or credential for founding membership
- No connection to Code Yaar's internal platform systems

## Success looks like

- One hundred founding members assembled through open applications
- Honest feedback that shapes the community and platform
- Practical learning activities run asynchronously across time zones
- A culture of building, sharing, and contributing established early
