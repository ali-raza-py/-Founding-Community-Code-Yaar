# Mission and Values

## Mission

Bring together motivated learners and aspiring developers from around the world to learn, build, exchange ideas, and help shape the future of Code Yaar — starting with one hundred founding members.

## Values

### Think
Understand the problem before reaching for a solution. Ask why something works, not only how to make it run.

### Build
Turn understanding into something real. Small, imperfect and finished beats large, ambitious and theoretical.

### Evolve
Use feedback to improve the work and the way you work. Then help someone else do the same.

## Community norms

- Build before you boast — evidence of work over claims about ability
- Learn by doing — output matters more than inputs
- Share what you discover — a solved error helps the group learn faster
- Give honest feedback — specific and kind, not vague and polite
- Grow together — help the next person move forward

## Audience

Beginners are the core audience. Advanced technical experience is not required. Curiosity, consistency, and a willingness to learn matter more than existing skill level.
