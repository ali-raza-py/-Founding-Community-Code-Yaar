# Brand and Positioning

## Relationship to Code Yaar

The founding community looks and feels like an official extension of Code Yaar, with its own dedicated identity as a global founding initiative. It inherits the official Code Yaar visual identity:

- Near-white neutral canvas (`#F7F8F5`)
- White card surfaces
- Dark readable text (`#19231D`)
- Emerald brand primary (`#087A52`) for important actions and emphasis
- Muted borders (`#E8ECE8`)
- Montserrat (headings), Figtree (body/UI), JetBrains Mono (technical labels)

## Positioning

- Early-stage, honest about what exists today vs. what is planned
- Global and asynchronous-first — time zones do not decide who can take part
- Practical, practice-first learning — not a course library
- Frontend-only community site; no backend integration

## What we avoid

- No purple, pink, neon blue, or rainbow accents
- No gradients as layout devices
- No mascots, bots, or decorative particles
- No generic AI website aesthetics
- No promises of jobs, internships, scholarships, or certifications

## Logo

Uses the official Code Yaar brand mark plus wordmark, with `logo-light.png` / `logo-dark.png` variants downloaded from the official Code Yaar frontend repository. Team portraits are actual founder photographs from the official repo.
