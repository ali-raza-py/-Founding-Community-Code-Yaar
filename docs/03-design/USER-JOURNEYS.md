# User Journeys

## Prospective member discovers the community

1. Lands on `/` homepage
2. Reads hero (campaign label, headline, supporting text)
3. Clicks "Explore the Cohort" → `/cohort`
4. Reads what the cohort is, who should apply, selection process
5. Clicks "Apply to The First 100" → `/apply`
6. Completes five-step form; draft saved in browser
7. Reviews summary on step 5, gives privacy consent
8. Submits; sees success state or honest error/retry

## Returning to finish an application

1. Opens `/apply`
2. Draft loads from localStorage automatically
3. Continues from where they left off
4. Submits; session guard prevents blank form after success

## Learning about the team

1. Navigates to `/about` via header
2. Reads Code Yaar introduction and philosophy (Think. Build. Evolve.)
3. Views founding team portraits (actual photographs)

## Finding answers

1. Navigates to `/faq` via header
2. Scans accordion questions (cost, countries, experience, selection, time, certificate, job, contact, GitHub)
3. Expands relevant answers

## Reviewing privacy

1. Navigates to `/privacy` via header or consent link
2. Reads data categories, collection/use/access/storage, rights, minors, security
3. Notes TBD items marked for founder confirmation

## Navigation (all pages)

- Header logo → home
- About / The Cohort / FAQ links
- Apply CTA (primary emerald button) on every page
- Mobile menu (hamburger, slide sheet, Escape to close)
