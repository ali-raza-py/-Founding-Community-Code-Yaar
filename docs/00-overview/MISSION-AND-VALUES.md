# Mission and Values

**Status:** Confirmed by the project brief.

## Mission

> Bring motivated learners together, encourage practical development, and create a community where people learn by doing and grow by contributing.

## Operating values

Each value has a **behavioural test** — the question we ask when a decision is unclear. Values without a test are decoration.

### 1. Build before you boast

**Test:** Does this ask someone to show work, or to describe themselves?
We prefer a rough project to a polished résumé line. Status claims need evidence.

### 2. Learn by doing

**Test:** Does this produce something the member actually made or solved?
Passive consumption (watch, read, collect) is allowed, but not the point.

### 3. Share what you discover

**Test:** Would another member benefit from hearing this?
A solved error, a useful tool, a wrong assumption corrected — all worth sharing.

### 4. Give honest feedback

**Test:** Is the feedback specific, kind, and actionable?
"Nice work" is not feedback. Neither is "this is bad".

### 5. Grow together

**Test:** Does this help someone else move forward, or only the person doing it?
Progress that is invisible to the group is half the value.

## How the values constrain the project

| Value | Constraint on the website and operations |
| --- | --- |
| Build before you boast | No member counters, no logos of partners, no "world's largest" language. Founding-member recognition is tied to participation, not to joining. |
| Learn by doing | Benefits are framed as activities and opportunities, not credentials. |
| Share what you discover | Application question 4 asks what the applicant could contribute, not only what they want to take. |
| Give honest feedback | FAQ and privacy copy state limits plainly (no job guarantee, no certificate promise). |
| Grow together | Selection criteria weigh collaboration and consistency as much as existing skill. |

## Values in the application form

The form deliberately asks for **contribution and realistic availability** alongside motivation, and does not score applicants on GitHub stars, institution prestige or existing skill level. See [`05-operations/APPLICATION-REVIEW-PROCESS.md`](../05-operations/APPLICATION-REVIEW-PROCESS.md).

## Non-values

Things Code Yaar does not compete on:

- being the biggest,
- being exclusive,
- being the fastest to a certificate,
- being the loudest on social media.
