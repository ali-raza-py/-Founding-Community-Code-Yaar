# Brand and Positioning

**Status:** Confirmed identity; visual system is an implementation recommendation.

## Brand identity

The community site is a **Code Yaar surface**. It must feel like an extension of the organization, not a separate club.

| Element | Rule |
| --- | --- |
| Name | "Code Yaar" always spelled out in prose. "The First 100" for the campaign. |
| Tagline | **Think. Build. Evolve.** — never paraphrased in headings. |
| Logo | Official Code Yaar mark, supplied as black-on-white artwork and prepared as transparent dark and light PNGs for the header and footer. |
| Voice | Direct, calm, specific. No superlatives. No growth-hack urgency. |

### Asset status

- The official Code Yaar mark is used in the header and footer via `public/code-yaar-logo.png` and `public/code-yaar-logo-light.png`.
- The favicon and Apple touch icon are generated from the mark as `src/app/icon.png` and `src/app/apple-icon.png`.
- No brand guideline PDF or font licence has been supplied; colours follow the brief's green/off-white direction rather than extracted brand tokens.

## Positioning statement

> The First 100 is the beginning of a global learning and building community for people who want to do more than simply learn programming — they want to practise, create, share, and contribute.

## Who it is for

Students, beginners, self-taught learners, aspiring developers and early builders who want a place to practise. Advanced experience is not a requirement. See [`../01-strategy/TARGET-AUDIENCE.md`](../01-strategy/TARGET-AUDIENCE.md).

## What makes it different

Not claims about scale. Claims about method:

| Common pattern | Code Yaar position |
| --- | --- |
| Watch a full course | Understand a concept, then use it |
| Collect certificates | Produce work you can show |
| Learn alone | Learn with people at a similar stage |
| Polite, vague feedback | Specific, actionable feedback |
| Member counts as success | Contribution as success |

## Global positioning

The cohort is open **worldwide**. The site must welcome applicants from South Asia, Southeast Asia, the Middle East, Africa, Europe, North and South America and elsewhere, without claiming existing international membership.

**Forbidden phrasing:**

- "Members from 40+ countries"
- "A global network of 10,000+ developers"
- "Partnered with universities worldwide"
- "Our international events"
- Any flag list or country counter that implies existing membership

**Allowed phrasing:**

- "Applications are open worldwide."
- "The founding cohort is being built from scratch, starting with this first group."
- "We expect members to join from different regions and time zones."

## Naming and terminology

Use these consistently in UI copy, docs and metadata:

| Use | Avoid |
| --- | --- |
| The First 100 | First100, First 100 Cohort Program |
| Global Founding Cohort 2026–27 | The 2026 batch, Cohort 1 |
| founding members | founding students, ambassadors |
| community | platform (when referring to the community) |
| Code Yaar platform | Code Yaar app, Code Yaar product suite |
| application | registration, sign-up |

## Voice guidelines

- Short sentences. One idea each.
- Name the reader's situation instead of describing our ambition.
- Prefer verbs: practise, build, share, review.
- Never use exclamation marks in body copy.
- No emoji in product UI.
- No false urgency ("Only 3 seats left!") — the cohort is capped at 100, which is a fact, not a countdown.

## Visual direction

Premium editorial, not startup-template. Deep forest green base, emerald accents, warm off-white paper, near-black type. Generous whitespace, strong hierarchy, thin rules, restrained shadows. Details in [`../03-design/DESIGN-DIRECTION.md`](../03-design/DESIGN-DIRECTION.md).
